Anatomy of an 0100

An authorization request asks the card's issuing bank: will you pay for this purchase? Below is one real-shaped ISO 8583 message for a $54.20 contactless tap at a restaurant. Click any part (a digit, a bit, a field, a bank) to see what it means, who sets it, and where to read more.

Tip: use ← → in a popover to step through, Esc to close.

The path it travels

Every hop adds or checks something. The whole round trip usually finishes in under two seconds.

The message, as it goes over the wire

ASCII-encoded ISO 8583 (1987). Read left to right: the message type, a bitmap saying which fields follow, then each field in number order. Grey dotted digits are length prefixes for variable-length fields.

Inside the bitmap

16 hex characters = 64 bits. Bit n is on when data element n is present. Click a hex digit or any bit, including the empty ones.
